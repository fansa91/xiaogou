# 小狗记账（Xiaogou Bookkeeping）

> 小狗记账是一款 Android 记账应用：记一笔收支、管理多个账户、按分类做月预算、
> 看月度与分类统计；同时支持周期记账、预算提醒、桌面小部件和账单 CSV 导出。

## 2. 功能总览

### 2.1 日常记账

- 记支出、记收入，选分类、选账户、填金额与备注。
- 分类可管理：新增、改名、换图标、开关、上移 / 下移排序、删除；记账时点大类可再选子类型。
- 记账键盘是自定义数字键盘，支持 + / − 累加、再记一笔、报销开关；日期用月历视图选，年份可直跳。
- 记账后同步更新对应账户余额；记录可查看详情、编辑、删除。

### 2.2 账户

- 多账户：新增时选类型（现金、银行卡、信用卡、支付宝、微信、股票、债券、基金、京东白条、转账、其他）和图标。
- 账户页：资产 / 负债 banner、饼图、列表 / 网格切换；详情有账单 / 变动记录 / 曲线三个页签，曲线可选周 / 月 / 季 / 半年 / 年 / 2–6 年范围。
- 账户间转账用自定义键盘；转账记录可删除（带确认，余额会冲回）；账户在名下无记账记录时可删除。

### 2.3 预算、周期、报销

- 月预算：按分类设预算，看已用 / 剩余 / 进度；点卡片看详情（总额、剩余、可日均、剩余天数）。
- 预算提醒：80% 即将用尽、100% 超支，同一预算同一月只提醒一次。
- 周期记账：每天 / 每周 / 每月 / 每年自动生成，漏跑可补跑（上限 100 条），每天 09:00 前后由 WorkManager 检查。
- 报销：新增、标记已报销、撤销已报销、删除。

### 2.4 统计与搜索

- 统计页：分类占比饼图 + 排行、柱状图、曲线图、近 6 个月趋势、全部类型、子类型饼图 + 合计；月份可前后翻，年份可直选。
- 搜索：按备注或账户名搜，结果行带账户名；搜索框为深色圆角 + 主题色按钮。

### 2.5 设置与应用锁

- 主题颜色 5 种（黄 / 绿 / 红 / 蓝 / 青），夜间模式三选（跟随系统 / 白天 / 夜间），换色换模式立即全应用生效。
- 货币符号开关（金额前加 ¥）、每月起始日（1–28 日，月份窗口从该日起算）、资产饼图开关、统计饼图开关。
- 应用锁：PIN 锁（只存 SHA-256 哈希）+ 指纹 / 面容解锁（设备支持时显示）；开机后会重新调度每日任务。

### 2.6 桌面小部件与导出

- 桌面小部件 5 个：快捷记账（点开直接进记账页）、今日（当天支出 / 收入 / 结余）、最新一笔、预算（本月第一条预算的已用 / 剩余 / 进度）、饼图（本月支出前 5 分类的环形图 + 图例）。应用回到前台时会刷新小部件。
- 账单导出：设置里导出全部账单或按起止日期导出，生成 CSV（日期、类型、分类、账户、金额、备注）后用系统分享发送；文件只写缓存目录。

## 3. 数据口径（旧数据接续）

- 数据库文件名 `MoneyKeeper.db` 不变；金额一律分、时间一律毫秒时间戳。
- 当前 Room 版本 6，迁移链 1→6 与旧版一致（5→6 只新建 `RecurringRecord` 表，不动旧数据）。
- 旧库实测见 `tools/old-db-test/RESULT.md`：按旧版 v5 CREATE 重建的等效旧库跑迁移后数据齐全、常用查询正常；最终真机打开确认仍待一份真实旧库文件。
- 备份服务端目录约定 `ElephantBookkeeping/` 保持不变（WebDAV 备份本身尚未实现，见下）。

## 5. 构建与发布

- 日常构建：推到 `main` 即触发 `.github/workflows/android.yml`，产出 5 个 debug APK（Artifacts）。
- 正式发布：打 `v*` / `phase-*` 标签触发 `.github/workflows/release.yml`，用仓库 Secrets 里的签名 keystore 出正式包并发布到 GitHub Releases；正式包与 debug 包签名不同，装过 debug 包的用户需先卸载再装正式包。
- 本地没有 JDK / Android SDK 时无法本地编译，以 GitHub Actions 结果为准。
